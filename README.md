# 🔐 Tela de Login

Projeto desenvolvido durante meus estudos de Front-End, com foco na criação e estilização de interfaces web.

## 📌 Sobre o projeto

Esta aplicação consiste em uma interface de login desenvolvida com HTML e CSS, buscando praticar a organização dos elementos e a construção de layouts.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 🎯 Objetivos de aprendizado

- Estruturação semântica com HTML.
- Estilização e personalização com CSS.
- Organização de elementos na página.
- Prática de construção de interfaces web.
